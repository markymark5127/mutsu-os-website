# Mutsu OS Website

Static site for [Mutsu OS](https://github.com/markymark5127/mutsu-os) — a Bazzite GNOME-derived Linux desktop with Japandi and Cyberpunk visual styles.

## Features

- Clean Japandi minimalist theme by default
- Instant switch to harsh-edged, glitchy, pixelated cyberpunk theme
- Sticky theme toggle button that follows you on scroll
- Live link to the latest ISO from the GitHub Releases page (falls back gracefully if none exist yet)

## Enable GitHub Pages

1. Go to the repository **Settings** → **Pages**
2. Source: Deploy from a branch
3. Branch: `main` / `/ (root)`
4. Save

The site will be available at:

**https://markymark5127.github.io/mutsu-os-website/**

## Local preview

Just open `index.html` in a browser, or use any static server.
