Why Mutsu

Quiet by design.
Powerful underneath.

Mutsu OS keeps the desktop out of your way. Soft materials, sensible defaults, and a system that updates itself and can roll back if anything goes wrong.

Mac-familiar

Window buttons on the left, a top-left menu, Super shortcuts that work like Command, and a 12-hour clock. You can change any of it.

Adaptive Desktop

On a 2-in-1 it's a full desktop when open and an app-grid Home with touch gestures when folded. It's on by default.

Ready for games

Steam, Proton and the drivers are already set up for desktops, handhelds and the living room. Install a game and play.

Mutsu Search

Press Super + Space to open a Spotlight-style launcher that finds apps and files instantly.

Mutsu Mechanic

A helper that lives in Search and runs on your computer, so you can ask it things offline. Cloud providers are opt-in, and your keys stay yours.

Atomic updates

Each update is a whole new system image. If something breaks, pick the previous version at boot and you're back.

Download

Try it live. Install when you're ready.

The live USB boots the full Mutsu desktop without touching your disk. If you like it, the installer is right there on the desktop.

Looking up the download parts…

Build the disk image

Join the parts into one bootable ISO

GitHub only allows files under 2 GB, so each ISO comes as a 7-Zip archive split into parts. Opening the first part puts the original .iso back together. It isn't compressed, so this only takes a few minutes.

Your computer
Download

  1. Download every part into one folder

    Get all the .7z.001, .002… parts and the .iso.sha256 file. You can also download them all at once with the GitHub CLI:

    gh release download v0.9.0-beta.20261115 --repo markymark5127/mutsu-os \
  --pattern 'mutsu-os-0.9.0-beta.20261115-live-online.iso*'

  2. Install 7-Zip

    # Fedora
sudo dnf install 7zip
# Debian / Ubuntu
sudo apt install 7zip

  3. Extract the ISO

    Open only the first part. 7-Zip finds the others in the same folder.

    7z x mutsu-os-0.9.0-beta.20261115-live-online.iso.7z.001

  4. Check the download

    It should print OK. If it doesn't, download the parts again.

    sha256sum -c mutsu-os-0.9.0-beta.20261115-live-online.iso.sha256

  5. Write it to a USB stick

    Use Fedora Media Writer and choose Custom image, or use dd. Run lsblk first to find your stick and replace /dev/sdX with it. This erases the USB stick.

    sudo dd if=mutsu-os-0.9.0-beta.20261115-live-online.iso of=/dev/sdX bs=4M status=progress oflag=sync

Then boot it. Plug in the stick, restart, and pick it from your boot menu (usually F12, F11, Esc or F2). You'll land on the live desktop. When you're ready to install, open the installer from the dock.

This is a beta. It's for testing, so try it live or in a virtual machine first, and back up anything important before you install on a computer you use every day. Please report bugs on GitHub.

Already on an atomic desktop?

Switch without reinstalling

If you run a bootc-based system, you can move to the Mutsu OS beta in place and switch back with bootc rollback.

sudo bootc switch ghcr.io/markymark5127/mutsu-os:beta
systemctl reboot
